# inaturalist-quality-control-pipeline
API Test Automation Framework built with Playwright and TypeScript, showcasing a modern QA approach with integrated CI/CD. This project is a demonstration of a Quality Engineer's mindset. 

It’s not just about running tests; it's about building a robust, maintainable, and scalable testing ecosystem.

# How to
INATURALIST_API_TOKEN - now 24 hours JWT-token used. Copy token on the page https://www.inaturalist.org/users/api_token and put here https://github.com/shtepbraiter/inaturalist-quality-control-pipeline/settings/secrets/actions
